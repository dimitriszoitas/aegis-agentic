# Spacing & Sizing

Use a shared rhythm from the inside of a control to the complete workspace. Choose a spacing role or a component size before creating a custom measurement.

## Spacing scale

Primitive dimensions supply the raw measurements. Semantic spacing roles form an ordered ramp from `--semantic-space-xxxs` through `--semantic-space-xxxxl`, with smaller optical and larger section roles where needed. The specimens inspect that semantic ramp. Production consumers use family group tokens, such as `--group-trigger-button-padding-snug`, rather than bypassing the group layer.

Responsive rules may select a smaller group role for the available space. They do not change the invariant meaning of the semantic spacing ramp. Inspect Tokens Used for the exact role selected by a component.

Use the nested inset for accordion bodies, navigation children, tree levels, JSON branches, and expanded table content. Keep page and section spacing separate from the compact spacing inside a control.

## Control sizing

Use the component's `size` property to change its full geometry together. Buttons and fields share small, medium, and large heights. Their CSS consumes family-owned height tokens. The public size names remain `sm`, `md`, and `lg`.

Avoid resizing a control through its height alone. Its typography, icon size, padding, and corner radius need to stay coordinated. Use the component's Tokens Used tab to inspect the complete mapping.

## Data density

DataGrid consumes the canonical group tokens `--group-data-display-measurement-grid-row-compact` (36px), `--group-data-display-measurement-grid-row-default` (48px), and `--group-data-display-measurement-grid-row-comfortable` (60px). These established public CSS names are retained; their manifest tier is group even though they do not use the `--group-` prefix. Expanded content is measured separately, so a density change does not clip nested content.

## Responsive composition

A wizard can separate progress and form content into top-aligned regions, with progress stacking above the form at narrow widths. Keep navigation and explicit approval within reach in its footer.

Application examples fill the available width up to 2160px and remain centered on wider screens. Smaller previews use responsive layouts. Fundamental Floating adds exterior container insets while keeping the same interior spacing roles.

## Overflow and scrollbars

Overflowing pages and nested regions share native scrollbar styling in both modes. Where supported, an 8px transparent track contains a 6px thumb with a 1px inset and 4px corners. The activity helper reveals thumbs while scrolling or using keyboard focus. The standards fallback uses a thin scrollbar, and forced-colors mode retains native styling.

Keep keyboard, wheel, touch, and native scrolling available. Avoid shrinking text or controls to make an overflowing composition fit.
